# ilmo — 기념일 관리

가족 기념일 14건을 한 파일로 관리하고, D-day와 캘린더 파일을 계산해서 뽑아낸다.
더데이비포(the day before) 앱 목록을 옮겨온 것이다.

```
data/ddays.yaml     정본 데이터 — 여기만 고치면 된다
scripts/dday.py     D-day 계산 / 검증 / ICS 생성
dist/ddays.ics      캘린더 파일 (생성물)
CLAUDE.md           Claude 비서용 작업 규칙
```

## 시작하기

```bash
pip install -r requirements.txt
python3 scripts/dday.py list
```

## 캘린더에 넣기

`dist/ddays.ics` 를 Google 캘린더 등에서 가져오기(import) 하면 된다. 당일 오전 9시 알림이 들어 있다.

- 양력 10건은 `RRULE:FREQ=YEARLY` 로 매년 반복된다 — 한 번 넣으면 계속 간다.
- 음력 4건은 반복 규칙으로 표현할 수 없어 **10년치를 개별 일정으로 펼쳐 넣었다**(2036년까지).
  기한이 다가오면 `python3 scripts/dday.py ics --years 10` 으로 다시 생성해서 넣으면 된다.

## 음력 처리

음력 생신 4건은 매년 양력 날짜가 달라져서, 계산할 때마다 `korean-lunar-calendar` 로 변환한다.
변환 결과는 앱이 표시한 D-day와 대조해 검증했다:

| 기념일 | 음력 | 변환된 양력 | 앱 표시 |
|---|---|---|---|
| 어머님 생신 | 09.13 | 2026-10-23 | D-53 ✓ |
| 아버지 생신 | 03.20 | 2027-04-26 | D-238 ✓ |
| 어머니 생신 | 04.29 | 2027-06-03 | D-276 ✓ |
| 아버님 생신 | 05.11 | 2027-06-15 | D-288 ✓ |

## 아직 채우지 못한 것

- **혜상 탄생 / 진호 생일**의 관계 — 그룹을 정하지 못해 `관계 미확인`으로 뒀다.
- **아버지·어머니 / 아버님·어머님** 구분은 호칭 관행에 따른 추정이다.
- **음력 4건의 출생연도** — 앱에 없어서 나이가 계산되지 않는다.

자세한 작업 규칙은 [CLAUDE.md](CLAUDE.md) 참고.
